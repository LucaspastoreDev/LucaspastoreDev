# 📄 Invoice Processing Agent

Um agente inteligente para extração e processamento de dados de invoices (faturas), construído com o **Agent Development Kit (ADK)** e integrado com modelos de IA.

---

## 🚀 Visão Geral

Este projeto automatiza a leitura e extração de informações de invoices em PDF ou imagem, como:

- Nome do fornecedor
- Valor total
- Data da fatura
- Itens da fatura
- Moeda

---

## 🧠 Arquitetura

O agente é baseado em:

- Agent Development Kit (ADK)
- Pipeline de processamento de documentos
- Integração com modelos de IA (ex: Gemini)
- Interface web (Playground / Dev UI)

---

## 📦 Requisitos

- Python 3.10+
- pip / uv
- Cloud Shell ou ambiente Linux/Mac
- API Key de IA (se aplicável)
